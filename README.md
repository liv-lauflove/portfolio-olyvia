# Olyvia Audy Djohari — Personal Portfolio Website

A modern, editorial, and high-performance personal portfolio website built with **React 19**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

Designed to showcase full-stack web development projects, technical skills, resume download, and direct contact channels.

---

## 🌟 Key Features

- **Editorial Hero Intro**: Centered portrait layout with custom typography, dark/light theme toggle, and smooth Lenis scrolling.
- **Interactive Tech Stack Marquee**: Continuous dual-row infinite marquee showcasing 18+ web technologies & tools.
- **Featured Projects Showcase**: 3D tilt cards with interactive project detail modal breakdown:
  1. **Luxury Villa Booking Platform** — Built with React & Supabase
  2. **Furniture Order Management System** — Built with Next.js, Prisma & PostgreSQL
  3. **Trisna Putra Baking Store** — Built with Laravel, PHP & MySQL
- **Magnetic Contact Section**: Instant email copying, LinkedIn, GitHub, and direct WhatsApp messaging.
- **Resume PDF Download**: One-click download for Olyvia's latest CV.
- **Responsive & Accessible**: Fully optimized across desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

- **Core**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Motion & Smooth Scroll**: Framer Motion, Lenis Scroll, React Fast Marquee
- **Icons**: Lucide React, React Icons (`react-icons/si`, `react-icons/fa6`)

## 🚀 Local Development Setup

```bash
# 1. Clone the repository
git clone https://github.com/liv-lauflove/portfolio-olyvia.git

# 2. Open project folder
cd portfolio-olyvia

# 3. Install dependencies
npm install

# 4. Start local dev server
npm run dev
```

Open `http://localhost:5173` in your browser to view the application.
